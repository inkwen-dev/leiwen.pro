# URL 对照表

**原则：** 地址栏 = 英文短路径；菜单/标题 = 中文。禁止拼音栏目名与英文混用。

| 菜单文案 | URL | 说明 |
|----------|-----|------|
| 雷文 | `/` | 首页 |
| 副业有术 | `/playbook` | 方法论栏目（地图等） |
| 副业导航 | `/links` | 精选网址（建设中可占位） |
| 关于 | `/about` | 人与定位 |
| 其它作品 | `/works` | 旧出海外链；仅页脚，不进顶栏 |
| （未开放）文章 | `/articles` | 有稿再挂菜单 |

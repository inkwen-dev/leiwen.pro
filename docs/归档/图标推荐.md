# Leiwen Pro 图标推荐

## 金色配色方案推荐

### 方案一：经典金色（推荐）
- **主金色**：`#D4AF37` (Gold)
- **深金色**：`#B8860B` (DarkGoldenrod)
- **浅金色**：`#FFD700` (Gold Light)
- **适用场景**：Logo、强调元素

### 方案二：奢华金色
- **主金色**：`#FFB000` (Amber Gold)
- **深金色**：`#E6A000` (Deep Amber)
- **浅金色**：`#FFD54F` (Amber Light)
- **适用场景**：高端品牌展示

### 方案三：温暖金色
- **主金色**：`#F5A623` (Warm Gold)
- **深金色**：`#D68910` (Dark Warm Gold)
- **浅金色**：`#F7DC6F` (Light Warm Gold)
- **适用场景**：友好、温暖的品牌形象

### 方案四：现代金色
- **主金色**：`#C9A961` (Modern Gold)
- **深金色**：`#A0826D` (Bronze)
- **浅金色**：`#E8D5B7` (Beige Gold)
- **适用场景**：现代、简约风格

### 方案五：亮金色
- **主金色**：`#FFC107` (Bright Gold)
- **深金色**：`#FF8F00` (Deep Bright Gold)
- **浅金色**：`#FFE082` (Light Bright Gold)
- **适用场景**：活力、创新品牌

**推荐使用方案一或方案三**，既体现金贵品质，又不过于张扬。

## 图标使用建议

1. **Logo图标**：推荐使用 **闪电/雷** 或 **小船**，体现品牌核心寓意
2. **装饰图标**：可在页面适当位置使用其他图标作为装饰元素
3. **颜色**：图标可使用金色（Pro部分）或主色调
4. **尺寸**：根据使用场景调整，保持简洁清晰

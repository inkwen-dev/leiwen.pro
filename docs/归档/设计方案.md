# Leiwen Pro 设计方案

## 设计原则

1. **品牌展示**：Leiwen Pro（Pro用金色）作为文字Logo，占据顶部少量位置
2. **品牌标语**：顶部展示"自由与梦想"，简洁有力，易于记忆
3. **项目名称为重点**：第一屏视觉焦点是项目名称，域名作为辅助信息
4. **简洁现代**：符合主流个人作品集网站审美
5. **出海项目展示**：突出项目的专业性和国际化

---

## 方案一：极简项目卡片（推荐）

### 设计理念
参考 Linktree、Carrd 等现代链接聚合页，突出项目名称，信息极简。

### 视觉布局
```
┌─────────────────────────────────────┐
│  Leiwen Pro  自由与梦想              │  ← 顶部固定，高度约60px
│  (Pro金色)                          │     Logo + 标语
├─────────────────────────────────────┤
│                                     │
│    ┌─────────────────────────┐     │
│    │                         │     │  ← 大卡片，高度100-120px
│    │  WallpaperSense         │     │     项目名称超大字号
│    │                         │     │
│    │  wallpapersense.com  →  │     │     域名小字号，辅助信息
│    └─────────────────────────┘     │
│                                     │
│    ┌─────────────────────────┐     │
│    │                         │     │
│    │  ContentQR              │     │
│    │                         │     │
│    │  contentqr.ai  →        │     │
│    └─────────────────────────┘     │
│                                     │
│    ... (其他项目)                   │
│                                     │
└─────────────────────────────────────┘
```

### 核心特点
- **顶部品牌区**：
  - Logo：Leiwen Pro（Pro用金色 #D4AF37），左对齐，字号16-18px
  - 标语："自由与梦想"，右对齐或居中，字号14px，灰色
  - 高度：60px，固定顶部
- **卡片设计**：
  - 大卡片（宽度100%，移动端适配）
  - 项目名称：超大字号（32-40px），粗体，主色，居中
  - 域名：小字号（12-14px），灰色，项目名称下方，右侧箭头图标
  - 描述：悬停时显示，淡入效果
  - 悬停：轻微上浮 + 阴影加深 + 项目名称颜色加深
- **间距**：卡片间距 16-20px，宽松呼吸感
- **颜色**：极简配色，深色模式友好，Pro用金色

### 优点
- ✅ 项目名称最突出，一目了然
- ✅ 品牌标语强化记忆点
- ✅ 现代感强，符合主流审美
- ✅ 移动端友好
- ✅ 加载快速，信息清晰

### 缺点
- ⚠️ 描述信息需要悬停显示

## 方案二：网格卡片 + 项目名称突出

### 设计理念
参考 Dribbble、Behance 作品集风格，网格布局，每个卡片独立展示，突出项目名称。

### 视觉布局
```
┌─────────────────────────────────────┐
│  Leiwen Pro  自由与梦想              │  ← 顶部，高度约60px
├─────────────────────────────────────┤
│                                     │
│  ┌──────────┐  ┌──────────┐        │
│  │          │  │          │        │  ← 2-3列网格
│  │ Wallpaper│  │ ContentQR│        │     项目名称超大
│  │ Sense    │  │          │        │
│  │          │  │          │        │
│  │ wallpapers│ │ contentqr│        │  ← 域名小字号
│  │ sense.com │ │ .ai      │        │     辅助信息
│  └──────────┘  └──────────┘        │
│                                     │
│  ┌──────────┐  ┌──────────┐        │
│  │ Startup  │  │ Inkwell  │        │
│  │ Sense    │  │ Flow     │        │
│  └──────────┘  └──────────┘        │
│                                     │
└─────────────────────────────────────┘
```

### 核心特点
- **顶部品牌区**：Leiwen Pro（Pro金色）+ "自由与梦想"标语
- **网格布局**：
  - 桌面：3列（xl:4列）
  - 平板：2列
  - 移动：1列
- **卡片设计**：
  - 项目名称：卡片中央，超大字号（36-48px），粗体，主色
  - 域名：项目名称下方，小字号（12-14px），灰色
  - 描述：悬停时显示在底部
  - 卡片比例：16:9 或 4:3
- **交互**：悬停时卡片放大 + 阴影加深 + 项目名称颜色加深

### 优点
- ✅ 视觉冲击力强
- ✅ 项目名称非常突出
- ✅ 适合展示多个项目
- ✅ 专业感强

### 缺点
- ⚠️ 需要更多垂直空间
- ⚠️ 移动端可能需要滚动

## 设计细节建议

### 颜色方案
- **品牌色**：Pro部分使用金色（#D4AF37 或 #F5A623）
- **主色**：蓝色系（#3B82F6）或根据项目调整
- **背景**：浅色模式白色，深色模式深灰
- **文字**：深色模式浅色，浅色模式深色
- **项目名称**：主色，悬停时加深
- **域名**：灰色，辅助信息

### 字体
- **Logo**：Leiwen（16-18px），Pro（金色，16-18px）
- **标语**："自由与梦想"（14px），灰色
- **项目名称**：32-48px（根据方案），粗体
- **域名**：12-14px，细字重，灰色
- **描述**：14px，细字重

### 动画
- **卡片悬停**：轻微放大（scale 1.02）+ 阴影加深
- **项目名称**：颜色过渡平滑，悬停时加深
- **描述**：淡入淡出（opacity 0 → 1）

### 品牌元素
- **Logo图标**：可选使用闪电/雷或小船图标（参考图标推荐文档）
- **品牌标语**："自由与梦想"，简洁有力，易于记忆
- **Pro颜色**：金色（#D4AF37），体现金贵品质

### 响应式断点
- 移动端：< 768px，1列
- 平板：768px - 1024px，2列
- 桌面：1024px - 1536px，3列
- 大屏：> 1536px，4列

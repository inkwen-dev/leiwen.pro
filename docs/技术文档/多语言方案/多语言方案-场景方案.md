## 场景一：静态内容网站

### 特点

- ✅ 内容相对固定
- ✅ 不需要数据库
- ✅ 内容在代码中或配置文件中
- ✅ 适合我们的项目（leiwen.pro）

### 方案 A：next-intl + JSON 文件（推荐）⭐⭐⭐⭐⭐

#### 实现方式

- 所有文本内容存储在 JSON 文件中
- 使用 next-intl 进行翻译
- 路由：`/en`, `/zh`

#### 优点

- ✅ 简单直接
- ✅ 性能好（构建时处理）
- ✅ 易于维护
- ✅ SEO 友好
- ✅ 版本控制友好（Git）

#### 缺点

- ❌ 需要手动维护翻译文件
- ❌ 内容更新需要重新构建

#### 适用性

⭐⭐⭐⭐⭐ 最适合我们的项目

#### 代码示例

**messages/en.json**
```json
{
  "projects": {
    "title": "Projects",
    "wallpapersense": {
      "name": "WallpaperSense",
      "description": "Discover beautiful wallpapers that understand your aesthetic sense"
    },
    "contentqr": {
      "name": "ContentQR",
      "description": "AI-Driven Marketing Content to QR Code"
    }
  }
}
```

**messages/zh.json**
```json
{
  "projects": {
    "title": "项目",
    "wallpapersense": {
      "name": "WallpaperSense",
      "description": "发现精美的壁纸，理解您的审美"
    },
    "contentqr": {
      "name": "ContentQR",
      "description": "AI驱动的营销内容转二维码"
    }
  }
}
```

**使用示例**
```typescript

  const t = useTranslations('projects');
  
  return (
    <div>
      <h2>{t('title')}</h2>

        <h3>{t('wallpapersense.name')}</h3>
        <p>{t('wallpapersense.description')}</p>
      </div>
    </div>
  );
}
```

## 场景二：有数据库内容的网站

### 特点

- ✅ 内容存储在数据库中
- ✅ 内容经常更新
- ✅ 需要 CMS 或后台管理
- ✅ 动态内容

### 方案 A：数据库多语言字段

#### 实现方式

- 数据库表中为每种语言创建字段
- 例如：`title_en`, `title_zh`, `content_en`, `content_zh`

#### 数据库设计示例

```sql
CREATE TABLE products (
  id INT PRIMARY KEY AUTO_INCREMENT,
  title_en VARCHAR(255),
  title_zh VARCHAR(255),
  description_en TEXT,
  description_zh TEXT,
  price DECIMAL(10, 2),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### 优点

- ✅ 查询简单
- ✅ 性能好（一次查询获取所有语言）
- ✅ 易于理解
- ✅ 不需要 JOIN

#### 缺点

- ❌ 添加新语言需要修改表结构
- ❌ 字段较多
- ❌ 维护复杂

#### 适用性

⭐⭐⭐⭐ 适合语言数量固定的项目（2-3种语言）

#### 代码示例

```typescript
// 查询示例
const product = await db.query(`
  SELECT 
    id,
    title_${locale} as title,
    description_${locale} as description,
    price
  FROM products
  WHERE id = ?
`, [productId]);

// 注意：这种方式有 SQL 注入风险，应该使用参数化查询
```

**安全的实现方式：**
```typescript
const localeMap = {
  en: 'title_en',
  zh: 'title_zh'
};

const titleField = localeMap[locale] || 'title_en';

const product = await db.query(`
  SELECT 
    id,
    ${titleField} as title,
    price
  FROM products
  WHERE id = ?
`, [productId]);
```

### 方案 B：数据库翻译表（推荐用于多语言）⭐⭐⭐⭐⭐

#### 实现方式

- 主表存储基础信息
- 翻译表存储多语言内容

#### 数据库设计示例

```sql
-- 主表（存储不依赖语言的数据）
CREATE TABLE products (
  id INT PRIMARY KEY AUTO_INCREMENT,
  price DECIMAL(10, 2),
  image_url VARCHAR(255),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 翻译表（存储多语言内容）
CREATE TABLE product_translations (
  id INT PRIMARY KEY AUTO_INCREMENT,
  product_id INT NOT NULL,
  locale VARCHAR(10) NOT NULL,
  title VARCHAR(255) NOT NULL,
  description TEXT,
  FOREIGN KEY (product_id) REFERENCES products(id) ON DELETE CASCADE,
  UNIQUE KEY unique_product_locale (product_id, locale)
);
```

#### 优点

- ✅ 易于添加新语言（只需插入新记录）
- ✅ 表结构清晰
- ✅ 适合多语言项目（3+种语言）
- ✅ 不需要修改表结构
- ✅ 符合数据库规范化原则

#### 缺点

- ❌ 需要 JOIN 查询
- ❌ 查询稍复杂
- ❌ 需要维护两个表的关系

#### 适用性

⭐⭐⭐⭐⭐ 适合需要支持多种语言的项目

#### 代码示例

```typescript
// 查询示例
const product = await db.query(`
  SELECT 
    p.id,
    p.price,
    pt.title,
    pt.description
  FROM products p
  INNER JOIN product_translations pt ON p.id = pt.product_id
  WHERE p.id = ? AND pt.locale = ?
`, [productId, locale]);

// 使用 ORM（如 Prisma）
const product = await prisma.product.findUnique({
  where: { id: productId },
  include: {
    translations: {
      where: { locale }
    }
  }
});
```

### 方案 C：JSON 字段存储

#### 实现方式

- 使用 JSON 字段存储所有语言

#### 数据库设计示例

```sql
CREATE TABLE products (
  id INT PRIMARY KEY AUTO_INCREMENT,
  title JSON,  -- {"en": "Product", "zh": "产品"}
  description JSON,
  price DECIMAL(10, 2)
);
```

#### 优点

- ✅ 表结构简单
- ✅ 易于添加语言
- ✅ 灵活性高

#### 缺点

- ❌ 查询复杂（需要 JSON 函数）
- ❌ 索引困难
- ❌ 不适合复杂查询
- ❌ 数据库兼容性问题

#### 适用性

⭐⭐⭐ 适合简单场景，不推荐用于生产环境

#### 代码示例

```typescript
// MySQL 查询示例
const product = await db.query(`
  SELECT 
    id,
    JSON_EXTRACT(title, ?) as title,
    price
  FROM products
  WHERE id = ?
`, [`$.${locale}`, productId]);

// PostgreSQL 查询示例
const product = await db.query(`
  SELECT 
    id,
    title->>$1 as title,
    price
  FROM products
  WHERE id = $2
`, [locale, productId]);
```

## 场景三：Blog 内容网站

### 特点

- ✅ 文章内容存储在数据库或文件系统
- ✅ 内容量大
- ✅ 需要 SEO 优化
- ✅ 可能需要 Markdown 支持

### 方案 A：Markdown 文件 + 多语言目录（推荐）⭐⭐⭐⭐⭐

#### 实现方式

- 每种语言一个目录
- 使用 Markdown 文件存储内容

#### 文件结构

```
content/
  blog/
    en/
      post-1.md
      post-2.md
    zh/
      post-1.md
      post-2.md
```

#### Markdown 文件示例

**content/blog/en/post-1.md**
```markdown
---
title: "Getting Started with Next.js"
date: "2024-01-01"
author: "Leiwen"
tags: ["nextjs", "react"]
---

# Getting Started with Next.js

Next.js is a React framework for production...
```

**content/blog/zh/post-1.md**
```markdown
---
title: "Next.js 入门指南"
date: "2024-01-01"
author: "Leiwen"
tags: ["nextjs", "react"]
---

# Next.js 入门指南

Next.js 是一个用于生产的 React 框架...
```

#### 优点

- ✅ 版本控制友好（Git）
- ✅ 易于编辑
- ✅ 支持 Markdown
- ✅ 构建时处理，性能好
- ✅ 不需要数据库
- ✅ 易于备份和迁移

#### 缺点

- ❌ 需要手动同步翻译
- ❌ 文件管理复杂
- ❌ 不适合大量内容

#### 适用性

⭐⭐⭐⭐⭐ 适合技术博客、文档网站、个人博客

#### 代码示例

```typescript
// lib/posts.ts
import fs from 'fs';
import path from 'path';
import matter from 'gray-matter';

const postsDirectory = (locale: string) => 
  path.join(process.cwd(), 'content', 'blog', locale);

export function getPosts(locale: string) {
  const dir = postsDirectory(locale);
  const filenames = fs.readdirSync(dir);
  
  return filenames.map((filename) => {
    const filePath = path.join(dir, filename);
    const fileContents = fs.readFileSync(filePath, 'utf8');
    const { data, content } = matter(fileContents);
    
    return {
      slug: filename.replace('.md', ''),
      ...data,
      content
    };
  });
}

export function getPost(slug: string, locale: string) {
  const filePath = path.join(
    postsDirectory(locale),
    `${slug}.md`
  );
  const fileContents = fs.readFileSync(filePath, 'utf8');
  const { data, content } = matter(fileContents);
  
  return {
    slug,
    ...data,
    content
  };
}
```

**使用示例**
```typescript
// app/[locale]/blog/[slug]/page.tsx
import { getPost, getPosts } from '@/lib/posts';
import { useLocale } from 'next-intl';

export default function BlogPost({
  params: { locale, slug }
}: {
  params: { locale: string; slug: string };
}) {
  const post = getPost(slug, locale);
  
  return (
    <article>
      <h1>{post.title}</h1>
      <div dangerouslySetInnerHTML={{ __html: post.content }} />
    </article>
  );
}
```

### 方案 B：数据库 + CMS（推荐用于内容管理）

#### 实现方式

- 内容存储在数据库
- 使用 CMS（如 Strapi, Contentful）管理

#### 数据库设计

```sql
-- 文章表
CREATE TABLE posts (
  id INT PRIMARY KEY AUTO_INCREMENT,
  slug VARCHAR(255) UNIQUE,
  author_id INT,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- 文章翻译表
CREATE TABLE post_translations (
  id INT PRIMARY KEY AUTO_INCREMENT,
  post_id INT NOT NULL,
  locale VARCHAR(10) NOT NULL,
  title VARCHAR(255) NOT NULL,
  content TEXT NOT NULL,
  excerpt TEXT,
  FOREIGN KEY (post_id) REFERENCES posts(id) ON DELETE CASCADE,
  UNIQUE KEY unique_post_locale (post_id, locale)
);
```

#### 优点

- ✅ 非技术人员可以编辑
- ✅ 内容管理方便
- ✅ 支持富文本编辑
- ✅ API 驱动
- ✅ 团队协作友好

#### 缺点

- ❌ 需要额外的 CMS 系统
- ❌ 成本较高
- ❌ 学习曲线

#### 适用性

⭐⭐⭐⭐ 适合需要内容管理的项目

#### CMS 选择

1. **Strapi**（开源，自托管）
2. **Contentful**（SaaS，付费）
3. **Sanity**（SaaS，有免费版）
4. **Prismic**（SaaS，有免费版）

### 方案 C：Headless CMS（推荐用于团队协作）

#### 实现方式

- 使用 Headless CMS（如 Contentful, Strapi, Sanity）
- 通过 API 获取内容

#### 优点

- ✅ 专业的内容管理
- ✅ 团队协作友好
- ✅ 多语言内置支持
- ✅ 版本控制
- ✅ 内容预览
- ✅ 工作流管理

#### 缺点

- ❌ 需要学习 CMS
- ❌ 可能有费用
- ❌ 依赖外部服务

#### 适用性

⭐⭐⭐⭐ 适合团队项目、企业网站

#### 代码示例

```typescript
// lib/contentful.ts
import { createClient } from 'contentful';

const client = createClient({
  space: process.env.CONTENTFUL_SPACE_ID!,
  accessToken: process.env.CONTENTFUL_ACCESS_TOKEN!
});

export async function getPosts(locale: string) {
  const entries = await client.getEntries({
    content_type: 'blogPost',
    locale
  });
  
  return entries.items.map((item: any) => ({
    slug: item.fields.slug,
    title: item.fields.title,
    content: item.fields.content,
    date: item.fields.date
  }));
}
```

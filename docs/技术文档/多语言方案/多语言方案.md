## 针对我们的项目（leiwen.pro）

### 推荐方案

**next-intl + JSON 文件** ⭐⭐⭐⭐⭐

### 理由

1. ✅ 我们的项目是 Next.js App Router
2. ✅ 内容主要是静态的（项目列表）
3. ✅ 简单易维护
4. ✅ 性能优秀
5. ✅ 易于扩展

### 实施步骤

1. 安装 `next-intl`
2. 创建 `messages/en.json` 和 `messages/zh.json`
3. 配置路由国际化
4. 迁移现有文本到翻译文件

**预计工作量：** 1-2 天

详细步骤请查看 [实现指南](./多语言方案-实现指南.md)

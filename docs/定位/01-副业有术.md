# 频道 · 副业有术（`/playbook`）

**副业有术解决什么：** 一个对副业、对「AI 能帮什么、怎么赚钱」还没有地图的人，打开栏目，看完结构，就能说出：副业有哪些大方向、自媒体/视频/平台怎么分、一种玩法靠哪些技能和 AI。

**上屏说法：** 访客看见的是方向和做法。页面上不写「图」「全屏查看」「玩法卡」。结构只是呈现方式。

**给谁：** 想做副业的人；用 AI 做事、想看清赚钱路径的人。

**用户得到什么：**

- 大方向一页（中文名：内容分发、电商与货、虚拟品与知识、AI 提效、AI 产品、出海、获客成交、本地实体、选事、社群）
- 每个大方向一页枝干（形态、平台、做法）
- 方向与玩法、技能、AI 能力、做事顺序
- 只有点进某一个玩法才读文字（一句话、适合谁、技能、AI、坑）

**站上纪律：**

- 首页与各图页是图。思维导图、流程图、关系图都可以。
- 访客看不见 `D1`、`D2`、`dir.d1` 这类内部代号。
- 详情页才允许成段文字。

**对标：** 生财里「方向 / 形态 / 平台 / 玩法」这种扫图方式。学结构，不搬会员原文。

## 两仓（互相独立）

| 仓 | 路径 | 放什么 | 谁读 |
|----|------|--------|------|
| 原料 | `playbook/原料/`（来源、研究、卡片、旧视图） | 生财灌入台账、全网补缺、内部研究、带 D 编号的旧图 | 网站不读 |
| 站点 | `playbook/站点/图/` | 15 张上屏图，节点只有中文 | 只有 `lib/playbook` |
| 玩法详情字段 | `playbook/data/map.json` | 玩法中文名与详情句子；id 仅作地址，不上屏 | 详情页只渲染中文名 |

改原料不会自动改网页。要改访客看到的图，只改 `playbook/站点/图/`。

## 玩法页五个架子

`/playbook/plays` 不平铺。一个玩法只进一个架子：沿 `parent` 走到大方向，再按下表归入。新玩法只要挂在已有方向下，会自动进对应架子。规则的代码主人是 `lib/playbook/groupPlays.ts`，页面不另写一份玩法名单。

| 架子 | 归入的大方向 |
|------|----------------|
| 做内容 | 内容与平台分发 |
| 卖东西 | 电商与货、本地与实体 |
| 卖知识 | 虚拟产品与知识变现 |
| 做产品 | AI 提效与工具、AI 产品与开发、出海 |
| 获客与选事 | 获客与成交、认知与选事、人群与社群运营 |

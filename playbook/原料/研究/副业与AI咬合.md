# 副业与 AI 咬合（研究）

> 原则：AI 卡是**能力层**；玩法用 `levered_by` 边挂上。不写工具名大全。

## 常见咬合

| 玩法类型 | 常挂 AI |
|----------|---------|
| 内容向 | 文本 / 图像 / 视频 / 音频生成 |
| 产品向 | 代码辅助 / 脚手架 / Agent |
| 获客向 | SEO 辅助 / GEO |
| 服务向 | 工作流 / 客服草稿 / RAG |

## 不解决什么

需求真伪、信任、合规、平台运气——这些不在 AI 卡承诺里。
